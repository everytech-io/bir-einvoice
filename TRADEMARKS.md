## Forks and modified versions

If you publish a modified version, publish it under your own Maven group, and **remove the
EveryTech logo**, so that users can tell it apart from the official releases. Say clearly that it
is a modified version of bir-einvoice and link to this repository. Keep the license and the
[NOTICE](NOTICE) file.

The official builds are the tagged releases of this repository (tags of the form `vX.Y.Z`) and
the artifacts built from those tags, such as the `com.github.everytech-io` artifacts that JitPack
builds from a tag (see the README, "Install"). Anyone who changes the code and publishes the
result is the publisher of that build, and is responsible for it.
